# Library Book Management System (LBMS)

A web-based library management application developed for QUT IFQ636 using React, Node.js, Express and MongoDB Atlas.

---

## Implemented Features

### User Management (LBMS-31)

- User registration and login.
- MongoDB Atlas integration.
- Reader and Librarian user roles.
- Reader role assigned automatically during registration.
- Librarian role assigned manually through MongoDB Atlas.
- Role-specific navigation:
  - **Librarian:** Catalogue, Profile, Logout.
  - **Reader:** Borrow, Profile, Logout.
- Original sample Tasks/CRUD navigation and route removed.

## Planned Features

### Catalogue Management
- Librarians can add, edit, search/read and delete/deactivate books. CRUD operation

### Book Borrowing
- Readers can browse available books and submit borrowing requests.
- Librarians can approve or reject borrowing requests.
